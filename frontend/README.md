# Frontend - Product CRUD

Interface web para gerenciamento de produtos.

## 🚀 Como Executar

1. **Certifique-se que o backend está rodando** na porta 3000

2. **Abrir o arquivo index.html** no navegador ou usar um servidor local:
```bash
# Opção 1: Servidor Python
python -m http.server 8080

# Opção 2: Live Server (VS Code)
# Instalar extensão Live Server e clicar com botão direito no index.html

# Opção 3: Servidor Node.js simples
npx serve .
```

3. **Acessar:** `http://localhost:8080` (ou porta escolhida)

## ✨ Funcionalidades

- ✅ Adicionar produtos
- ✅ Listar produtos
- ✅ Editar produtos (via prompt)
- ✅ Excluir produtos
- ✅ Buscar produto por ID
